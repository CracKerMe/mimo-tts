### 关键踩坑（zod v4，可复用）
1. **`z.coerce.boolean()` 会把字符串 `"false"` 误判为 true**（`Boolean("false")===true`）。env 布尔值须用 `z.preprocess` 显式映射 `"true"/"1"` → true，其余 → false。本项目曾因此让 `MIMO_TTS_REQUIRE_AUTH=false` 实际变成 true。
2. **`.omit()` 不能用于带 `.superRefine()` 的 schema**（报错 `.omit() cannot be used on object schemas containing refinements`）。解决：先定义无 refine 的 base schema，派生 tool schema（omit）和带 refine 的校验 schema。
3. **`zod-to-json-schema` 3.x 不能正确解析 zod v4 schema**（返回 `$ref` 指向 OpenAiAnyType / any）。改用 **zod v4 内置 `z.toJSONSchema(schema)`**，开箱即用，无需额外依赖。
