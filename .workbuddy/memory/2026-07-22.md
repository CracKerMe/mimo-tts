## mimo-tts 扩展可行性分析
- 抓取小米语音合成 API v2.5 文档（mimo.mi.com），通读项目 4 个源文件 + CODE_REVIEW.md。
- 产出报告：`docs/mimo-tts-extension-analysis.md`。
- 关键发现：项目已覆盖文档绝大多数已声明能力（三模型、风格控制、流式、安全）；真正缺口在易用性/产品化层（角色配置、风格预设、音色列表、用量可观测、批量编排）。
- 重要约束：API 不暴露数值化音频参数（rate/pitch/volume/采样率/位深/声道），"精确音频参数动态调整"不可行，只能 NL/标签软控制。输出固定 24kHz PCM16LE mono，仅 wav/pcm16。voicedesign/voiceclone 流式降级为兼容模式。
- Top3 推荐：① 角色配置+风格预设+音色列表端点（A/E/F）；② 用量可观测（G）；③ 流式 WAV 封装（D）。批量/队列（C）列为第二里程碑。
